# Физика в действии

Интерактивная лаборатория для самостоятельного изучения физики: понятное объяснение → предположение → эксперимент → решение задачи → проверка.

**[Открыть работающий сайт](https://physics-in-action-lab.young-isle-4822.chatgpt.site/)**

В репозитории находятся две версии: локальное приложение с сервером ИИ и опубликованный сайт на платформе Sites. Учебная история в обеих версиях хранится в браузере; для переноса используется резервная копия JSON.

## Что умеет сервис

- **Полный курс:** 27 тем по механике, молекулярной физике, термодинамике и электростатике. Объяснения, разобранные примеры и 135 вопросов с разбором.
- **Подготовка за один день:** 10 модулей по плану от 16 октября — основы, шесть опорных блоков, обзор, устные ответы и задачи. 53 тренировочных вопроса, расписание и сокращённый вариант на 6 часов.
- **Шесть лабораторных маршрутов:** движение по прямой, окружность, измерения, идеальный газ, световые часы и электрическая цепь.
- **Игровая площадка:** свободные эксперименты с параметрами моделей, таблицы измерений, собственные предположения и выводы.
- **Мастерская:** импорт PDF/DOCX, создание модуля из документа или описания темы, просмотр и исправление результата перед добавлением.
- **Чат с ИИ:** вопросы по выбранному модулю с учётом его материала; история разговора сохраняется отдельно для каждой темы.
- **Anatomy:** создание параметрических SVG-сцен по описанию, ползунки и показания, исследования на игровой площадке. Сцены проверяются по схеме; произвольный код модели не выполняется.
- **Результаты:** баллы, процент прохождения, история ответов и опытов, повторение, экспорт, импорт и печатный отчёт.

Курс — самостоятельная краткая адаптация [материалов ЮФУ](https://lms.sfedu.ru/course/view.php?id=1216). Она не заменяет полные лекции и оценки LMS. В пробной пересдаче самооценка устного ответа **0–24** ведётся отдельно от автоматических баллов приложения **0–100**.

## Быстрый запуск на компьютере

Нужны **Node.js 22.13+** и npm. Текущая версия проверена на Node.js 26.9.0.

```sh
git clone https://github.com/FlexGodX/PhysicsLab.git
cd PhysicsLab
npm ci
npm run dev -- --port 5174 --strictPort
```

Откройте **[http://127.0.0.1:5174/](http://127.0.0.1:5174/)**. Оставьте терминал с сервисом запущенным. Для остановки нажмите `Ctrl+C`.

Курс, встроенные симуляции и результаты работают без подключения ИИ. Чтобы пользоваться чатом и генерацией, откройте **Настройки → Подключение ИИ**.

Для проверки собранной версии:

```sh
npm run build
npm run preview -- --port 5174 --strictPort
```

Обе команды запуска (`dev` и `preview`) подключают локальный сервер ИИ. Открытие `dist/index.html` напрямую или раздача `dist/` простым статическим сервером не заменяют этот сервер.

## Как подключить ИИ

| Сервис | На компьютере | На опубликованном сайте |
| --- | --- | --- |
| LM Studio | Локальный сервер и имя загруженной модели | Не подключён |
| Codex по подписке ChatGPT | Установленный Codex CLI и вход через ChatGPT | Не подключён: Sites не запускает CLI |
| OpenRouter, OpenAI, Anthropic, Gemini | API-ключ и идентификатор модели | API-ключ, загрузка/поиск моделей или ручной идентификатор |
| DeepSeek, Qwen, NVIDIA NIM | Через опубликованную версию | API-ключ и выбор модели |
| Ollama | Через опубликованную версию | Ollama Cloud или собственный общедоступный HTTPS-сервер |

### LM Studio

1. Загрузите модель в LM Studio и запустите Local Server.
2. В настройках лаборатории выберите **LM Studio**.
3. Укажите имя модели и адрес, например `http://127.0.0.1:1234/v1`.
4. Сохраните настройки и нажмите **Проверить соединение**.

### Codex по подписке

Установите [Codex CLI](https://developers.openai.com/codex/cli), затем выполните:

```sh
codex login
```

Войдите через ChatGPT и выберите **Codex** в настройках локальной лаборатории. Можно также начать вход кнопкой в интерфейсе. Поле модели разрешено оставить пустым — будет использована стандартная модель CLI. При нестандартном расположении CLI путь задаётся переменной `PHYSICS_CODEX_BIN`.

Приложение использует существующий вход CLI и лимиты подписки; токены входа не копируются в проект. Вход с API-ключом не считается подписочным. Этот режим поддерживает текстовые ответы и генерацию данных модулей/сцен, без выполнения сгенерированного кода.

### API-провайдеры на сайте

1. Откройте сайт, войдите через ChatGPT и перейдите в **Настройки → Подключение ИИ**.
2. Выберите провайдера и введите его API-ключ.
3. Загрузите список моделей или введите точный идентификатор вручную.
4. Сохраните настройки и проверьте соединение.

У каждого провайдера свои ключ и модель. Пустое поле сохраняет прежний ключ; отдельная кнопка удаляет его. Проверка соединения отправляет настоящий запрос и может расходовать баланс.

Для Ollama используйте Cloud или публичный HTTPS-домен: размещённый сайт не может обратиться к `localhost` вашего компьютера. Для Qwen предусмотрен выбор региона.

## Данные и ограничения

- История хранится в **IndexedDB**. Адрес и порт определяют отдельное хранилище: локальная версия и сайт не синхронизируют записи автоматически.
- Для переноса откройте **Настройки → Экспорт/импорт JSON**. Импорт проверяется перед заменой; подтверждение замены выполняется отдельно.
- Локальные ключи находятся в `.physics-lab/providers.json`, исключены из Git и резервных копий курса. Локальный сервер рассчитан на запуск на `127.0.0.1`.
- На сайте ключи хранятся в D1, зашифрованы AES-256-GCM и разделены по авторизованным пользователям. Они не возвращаются в браузер и не входят в экспорт учебной истории.
- PDF/DOCX разбираются на устройстве. При генерации выбранному сервису передаётся извлечённый текст, а не исходный файл. Лимиты: **10 МБ**, **100 страниц PDF**, **60 000 символов**. Для сканов без текста нужен внешний OCR.
- До **100 личных модулей** и **100 визуализаций**. Качество объяснений и физики новых сцен зависит от модели и требует содержательной проверки.
- Встроенные лаборатории используют специализированные модели. Anatomy создаёт параметрические сцены, а не универсальный движок произвольных тел и сил.

## Исходники опубликованного сайта

Версия Sites находится в [`sites/physics-lab`](sites/physics-lab/README.md). У неё собственные зависимости, серверные обработчики и хранилище настроек ИИ.

```sh
cd sites/physics-lab
npm run install:ci
npm run dev -- --port 5180 --host 127.0.0.1
```

Сайт откроется на `http://127.0.0.1:5180/`. В локальном предпросмотре доступен штатный тестовый вход Sites; в публикации личность посетителя задаёт сама платформа. Настройка D1 и серверного ключа шифрования описана в [README веб-версии](sites/physics-lab/README.md).

**GitHub хранит исходники.** Рабочая публикация выполняется через Sites с архивом сборки и точным коммитом исходников. GitHub Pages не заменяет серверные функции ИИ, D1 и авторизацию.

## Проверки

```sh
npm test
npm run build
```

Браузерные сценарии для локальной версии (требуется установленный Google Chrome):

```sh
npm run e2e:chrome -- --workers=2 --grep-invert 'восемь провайдеров|без входа настройки'
```

Два сценария настроек провайдеров предназначены для сервера Sites. Полный набор проверок опубликованной сборки запускается из корня при работающем предпросмотре Sites:

```sh
PHYSICS_SITE_BASE_URL=http://127.0.0.1:5181 npx playwright test --config playwright.hosted.config.ts --workers=2
```

Настройка production-предпросмотра: [README веб-версии](sites/physics-lab/README.md#проверка-собранного-сайта).

Для поставляемого Playwright Chromium вместо установленного Chrome:

```sh
npx playwright install chromium
npm run e2e -- --grep-invert 'восемь провайдеров|без входа настройки'
```

Последняя проверка учебных изменений: **111 тестов Vitest**, **14 браузерных сценариев веб-версии**, сборки обеих версий. Подробности: [протокол](docs/verification/2026-10-16-day-plan.json). Запросы к платным API в автоматических сценариях подменяются; наличие тестов не означает проверку каждой платной модели.

## Структура проекта

| Каталог | Содержимое |
| --- | --- |
| `src/content` | Материалы, 27 тем LMS, однодневный план, задания и версии |
| `src/physics` | Математические модели и единицы СИ |
| `src/learning` | Проверка ответов, прогресс, советы и повторение |
| `src/persistence` | Схемы резервных копий и IndexedDB |
| `src/studio`, `src/figures` | Документы, личные модули и сцены Anatomy |
| `src/ui` | Интерфейс React и SVG |
| `server` | Локальный API, провайдеры ИИ и интеграция Codex CLI |
| `sites/physics-lab` | Серверная веб-версия для Sites |
| `tests`, `e2e` | Тесты логики и браузерные сценарии |
| `docs` | Спецификации, паспорта моделей, планы и результаты проверок |

Технологии: **React, TypeScript, Vite/Vinext, Zod, IndexedDB, KaTeX, Vitest, Playwright**; веб-версия использует **Cloudflare Workers и D1**.
