# Codex по подписке

Запрос: подключить к лаборатории агента Codex, авторизованного по подписке.

Codex становится шестым сервисом для существующих чата, генерации модулей и визуализаций. Локальный сервер запускает установленный Codex CLI через `codex exec`; используется вход ChatGPT, API-ключ не требуется. Пустое имя модели означает выбор по умолчанию Codex. При отсутствии CLI или входа показывается действие для подключения. Настройки остальных сервисов сохраняются.

В настройках доступны проверка статуса, вход через код устройства и отмена незавершённого входа. Учётными данными управляет CLI: приложение не читает auth.json, не получает токены и не включает их в учебную историю или резервную копию. Вход действует для Codex на этом компьютере; интерфейс поясняет расход лимитов подписки.

Запрос передаётся через stdin, без shell и без вставки в командную строку. Агент работает во временном каталоге в read-only режиме, без пользовательской конфигурации, shell, MCP из конфигурации, приложений и браузера. Ответ используется только как текст или проверенные данные существующей схемы; выполнение сгенерированного кода не добавляется. Отмена, таймаут, отсутствующий CLI, API-вход вместо подписки, лимит и пустой ответ имеют понятные сообщения. Процессы и временные файлы удаляются после завершения. Не допускается незаметное переключение на платный API.

Проверка: отдельный исполняемый CLI-стенд для протокола процесса и отказов, HTTP-тесты локальных маршрутов, браузерный сценарий настройки и чата, реальный короткий запрос к уже авторизованному Codex без изменения активного сервиса пользователя.

Источники: https://developers.openai.com/codex/auth и https://developers.openai.com/codex/noninteractive, проверены 15.10.2026. Установлен Codex CLI 0.154.0, локальный статус: вход ChatGPT.
