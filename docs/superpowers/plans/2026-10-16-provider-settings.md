# Провайдеры и модели в настройках сайта

**Goal:** пользователь вводит ключ провайдера в настройках, выбирает модель, проверяет соединение и использует чат, генерацию модулей и Anatomy.

**Architecture:** общий реестр восьми провайдеров: OpenRouter, OpenAI, Anthropic, Gemini, DeepSeek, Qwen, NVIDIA NIM, Ollama. Отдельные настройки каждого провайдера хранятся в D1 с привязкой к посетителю. API-ключ шифруется AES-GCM ключом из секретов Sites, не возвращается браузеру и не входит в экспорт учебной истории. Каталоги моделей загружаются с официальных API; доступен ручной идентификатор. Ollama Cloud либо собственный общедоступный HTTPS-сервер, не localhost.

Не загружать существующие локальные ключи в сайт. Генерировать только ключ шифрования сервера. Реальные платные запросы не заявлять проверенными без введённых пользователем ключей. Предыдущий запрос о подключении Codex исследован, реализация моста не начиналась; текущая работа посвящена запрошенным провайдерам API.

Результат: 106 тестов, 11 браузерных сценариев, проверки типов и сборка прошли. OpenRouter фактически вернул 465 моделей без платного запроса. Во время работы доступ сайта сменился на публичный (ревизия 2); общий режим владельца удалён до публикации, настройки изолированы по авторизованному посетителю. Версия 3 опубликована стандартной операцией Sites.
