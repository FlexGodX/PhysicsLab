# Веб-версия лаборатории через Sites

**Goal:** опубликовать рабочую приватную веб-версию существующего сервиса с курсом, опытами и локальной историей.

**Architecture:** отдельный каталог `sites/physics-lab` на предоставленном Vinext-шаблоне. Существующее приложение React переносится без личных данных и исходных PDF. Облачные ИИ-запросы обслуживаются сервером сайта с ключами из секретов Sites; выбор провайдера и модели хранится в браузере без ключей. Codex CLI и LM Studio доступны только в исходной локальной версии.

**Tech Stack:** React, Vinext, Sites Worker, Zod, IndexedDB, существующие тесты и отдельные тесты серверного адаптера.

Ограничения: новый домен имеет отдельное локальное хранилище; пользователь может перенести свои записи через существующий JSON. Нет переноса университетского входа, оригинальных PDF, .physics-lab или токенов Codex. Ключи облачных провайдеров не предоставлены: реальный платный запрос не выполнять и не изображать проверенным. Подключение ключей выполняется средствами секретов Sites.
