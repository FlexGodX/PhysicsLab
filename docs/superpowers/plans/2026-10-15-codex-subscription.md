# Codex Subscription Implementation Plan

> **For agentic workers:** выполнить задачи последовательно в текущем сеансе; запрос пользователя включает реализацию.

**Goal:** Подключить Codex с существующей подпиской к чату и генерации материалов лаборатории.

**Architecture:** шестой провайдер вызывает локальный Codex CLI. Отдельные модули управляют ограниченным дочерним процессом, статусом и входом; существующий API проверяет Origin и результаты генерации.

**Tech Stack:** Node.js child_process, TypeScript, React, Vitest, Playwright.

**Spec:** docs/specs/2026-10-15-codex-subscription.md

## Global Constraints

- Без API-ключа и автоматического перехода на API.
- Не читать и не передавать токены; не менять авторизацию без явной команды входа.
- Временный каталог, read-only, запуск без shell, запрос через stdin.
- Сохранить существующие подключения и учебные данные.

## Review Focus

- Отсутствующий CLI: понятное сообщение, без зависания.
- Вход с API-ключом: запрос по подписке отклоняется до обращения к модели.
- Отмена/таймаут/объём вывода: процесс завершается, каталог удаляется.
- Неверный Origin: не запускается даже проверка статуса или вход.
- Смена сервиса во время настройки: ответ статуса не подменяет выбранный сервис.
