# L1: движение по прямой, модель 1

## Величины и диапазоны

| Параметр | Единица СИ | Допустимый диапазон | Старт |
| --- | --- | --- | --- |
| x₀ | м | −20…20 | 0 |
| v₀ | м/с | −10…10 | 0 |
| a | м/с² | −5…5 | 2 |
| длительность | с | 1…10 | 4 |
| t | с | 0…длительность | 0 |

Все числа конечны. Модель отклоняет значения вне диапазона. Ввод понимает запятую и точку, пустое поле не становится нулём.

## Уравнения

x(t) = x₀ + v₀t + at²/2; v(t) = v₀ + at; Δx = x(t) − x₀.

Путь равен интегралу |v|. Если a ≠ 0 и момент −v₀/a лежит строго внутри интервала, сумма модулей перемещений до и после разворота вычисляется отдельно. При a = 0 деление на ускорение отсутствует.

Постоянное ускорение; одна ось направлена вправо; тело — материальная точка. Силы, сопротивление, столкновения и изменение ускорения внутри запуска не моделируются. Координата, векторы, числа, таблица и графики используют одну функцию `linearState`.

Проигрывание меняет только выбранное модельное время. После пропущенного кадра вычисление не накапливает ошибку интегрирования. На графике 161 равномерная точка плюс точный момент разворота, если он существует. Экспортируемый опыт сохраняет разреженную выборку, включая начальное/конечное состояния и разворот.

## Контрольные значения

- x₀=0,v₀=0,a=2,t=4: x=16 м, v=8 м/с, путь=16 м; за секунды 1,3,5,7 м.
- v₀=2,a=−1,t=4: перемещение=0, путь=4 м, v=−2 м/с.
- v₀=−3,a=0,t=4: перемещение=−12 м, путь=12 м.
- v₀=4,a=−1,t=4: v=0, путь=8 м, ускорение по-прежнему −1 м/с².
- Путь не меньше модуля перемещения.

Допуск ядра и проверки импортированных измерений: max(10⁻⁹ единицы СИ, 10⁻⁹ × |эталон|). Числовые ответы ученика принимаются с допуском 1% + 10⁻⁹; единицы проверяются отдельно. Допустимые преобразования: м/см/км, м/с и км/ч. Ускорение — м/с², время — с.
